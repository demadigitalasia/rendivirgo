# RENDI VIRGO — SEO audit and implementation

Date: 23 October 2026 (Asia/Jakarta).

## Scope and evidence

This is a source-code audit of the local project plus an implemented tool for auditing actual public HTML. It is not a completed production crawl of rendivirgo.com. The connected browser denied page observation under its URL security policy, so visual verification and a populated live crawl report could not be completed in this session. No production rankings, Core Web Vitals, Search Console data, or numeric site-wide SEO score are claimed.

## Editorial score

Available in Products, Categories, Blog, Pages, and Home page editors. English and Indonesian are analysed separately. Lists calculate from the current saved English content. Scores themselves are derived, not stored as potentially stale database fields. Saving content makes the next calculated score use the updated fields.

| Check | Weight |
| --- | ---: |
| Descriptive title | 10 |
| Explicit SEO title | 15 |
| Meta description | 15 |
| Readable slug (homepage root accepted) | 10 |
| Useful content length, adjusted to type | 20 |
| Topic consistency across title/body/metadata | 10 |
| Paragraph readability | 5 |
| H2/H3 headings, for pages and blog posts | 5 |
| Relevant internal body link, for pages and blog posts | 5 |
| Images and alt text, for blog posts | 5 |
| Images and alt text, for products/categories/home | 15 |

Applicable checks are normalised to 100. Pages without an image check are scored from their applicable 95-point total. Content targets are editorial prompts: product 100, article 300, page 150, category 35, homepage 100 words. These are not Google minimums. The topic is inferred from the page title, not a persisted user-defined focus keyphrase. This is not a full Yoast implementation: it does not score synonyms, linguistic keyphrase variants, backlinks, or keyword difficulty.

Bands: 80–100 Good, 50–79 Needs work, 0–49 Needs attention. A 100 does not guarantee indexing, rich results, traffic, or ranking. Metadata lengths of roughly 30–60 and 120–160 characters are useful editing guides, not hard Google limits.

## Public technical audit

Open /admin/seo and select **Run public-page audit**. This loads current sitemap URLs and language alternates, then scans same-origin HTML with three concurrent workers, per-request timeouts, progress, cancellation, type/search filters, and failed-request reporting. Scan results are a snapshot held in the current page; rerun after saving changes or reopening the audit page.

Checks: title 15, description 15, H1 10, canonical path 10, indexability meta tags 10, image alt attributes 10, heading hierarchy 5, descriptive links 5, JSON-LD syntax/expected type 10, social tags 5, document language 5. Duplicate titles/descriptions lose their corresponding points within the same language. Failed URLs have no score and are excluded from the average. Empty alt attributes on intentionally decorative images are accepted.

This is a different score from editorial completeness. It cannot prove crawlability under robots.txt or HTTP X-Robots-Tag, fully validate Google rich results, verify canonical query-string policy, determine search rankings, or measure Core Web Vitals. Scan coverage is limited to URLs advertised in the current sitemap; unpublished drafts are reviewed in their content editors. Banners and testimonials are page blocks, not separate indexable URLs, so their rendered contribution is checked on the containing page. No AI-generated testimonials or fabricated reviews are introduced.

## AI workflow

Existing full-copy generators on products, blog, and categories remain available. Added tools use the existing OpenRouter credentials/model from Admin Settings, through authenticated and throttled API routes. Nothing calls a paid provider automatically.

New generators show editable previews, then apply only their allowed fields to the form; they do not save or publish. Source-change detection prevents applying an outdated draft after its supplied source changed. Applying bilingual metadata/content sets the translation to Review. Banner drafts preserve CTA URLs and image settings. Prompts require verified facts and prohibit invented gemstone properties, personal history, policies, shipping promises, certifications, and URLs.

Provider outputs are validated for required fields and character limits; empty/malformed/truncated responses are rejected. Missing configuration, insufficient credits, rate limits, and connectivity failures are reported. Validation is tested with mocked responses; a real paid generation was not performed.
