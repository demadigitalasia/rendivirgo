# Google Search guidance for evaluating an SEO Score

Date: 25 October 2026 (Asia/Jakarta).

This memo records primary-source guidance from Google Search Central to use when assessing an on-page SEO scoring feature. Google does not publish a universal 0–100 page-level SEO score, official checklist weights, or a guaranteed ranking formula. A product score is therefore an editorial/diagnostic heuristic; it must not be presented as Google's score, a ranking prediction, or a guarantee of indexing or traffic.

## Evidence by topic

| Core practices | Prioritize helpful, reliable, people-first content; use words people search for in prominent places such as title and main heading; make links crawlable; apply appropriate image, video, structured-data, and JavaScript guidance. Google says there are few technical requirements and most sites meet them without realizing it. | [Google Search Essentials](https://developers.google.com/search/docs/essentials) |
| Content quality | Self-assess originality, completeness, added value, accuracy, clear authorship/experience, and whether content satisfies readers. Google explicitly says there is no preferred word count and that length alone does not matter for ranking; excessive keyword repetition is spam. E-E-A-T is not itself a specific ranking factor. | [Creating helpful, reliable, people-first content](https://developers.google.com/search/docs/fundamentals/creating-helpful-content); [SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) |
| Titles | Give every page a descriptive, concise, distinct `<title>`; avoid boilerplate and keyword stuffing. Google can rewrite title links using the page's visible title, headings, prominent text, links, and other sources. Google sets no fixed `<title>` character limit; result display truncates as needed for device width. | [Influencing title links in search results](https://developers.google.com/search/docs/appearance/title-link) |
| Snippets and descriptions | Google primarily generates snippets from page content and may use a meta description when it is a better summary. Descriptions should be useful, accurate, and page-specific. There is no fixed meta-description length limit; display truncates to fit. The meta description is not a direct ranking score/guarantee. | [Control your snippets in search results](https://developers.google.com/search/docs/appearance/snippet); [SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) |
| Crawling and indexing | Discovery, crawling, indexing, and serving are separate processes; indexing is not guaranteed. `robots.txt` controls crawling, not reliably index exclusion; use `noindex` (and permit crawling so Google can see it) or access controls to prevent indexing. Sitemaps are hints, not guarantees or immediate crawl requests. Canonicals are signals/preferences Google may evaluate. | [How Google Search works](https://developers.google.com/search/docs/fundamentals/how-search-works); [robots.txt guide](https://developers.google.com/search/docs/crawling-indexing/robots/intro); [Sitemaps overview](https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview); [Canonicalization](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls) |
| Structured data | Valid structured data may make a page eligible for a rich result, but appearance is not guaranteed. Violations can remove rich-result eligibility; a structured-data manual action does not affect ordinary web-search ranking. Therefore score validity/eligibility and user-facing rich-result appearance separately. | [General structured data guidelines](https://developers.google.com/search/docs/appearance/structured-data/sd-policies) |
| Links | Google generally parses `<a href>` links. Contextual internal links help discovery and understanding; every important page should be linked from at least one other page. Google says there is no magical ideal number of links. Qualify paid links with `sponsored` (or `nofollow`) and user-submitted links with `ugc`/`nofollow`. | [Link best practices](https://developers.google.com/search/docs/crawling-indexing/links-crawlable); [Qualify outbound links](https://developers.google.com/search/docs/crawling-indexing/qualify-outbound-links) |
| Images | Descriptive, contextual alt text helps accessibility and image understanding; Google uses it alongside computer vision and surrounding page content. Alt should not be keyword stuffed. Filenames may provide light clues, not a strong scoring substitute for image relevance/accessibility. | [Google Images SEO best practices](https://developers.google.com/search/docs/appearance/google-images) |
| Page experience and CWV | Core Web Vitals (LCP, INP, CLS) are used by ranking systems, but good scores do not guarantee top ranking and a perfect score solely for SEO may not be a good use of time. Page experience is holistic; no single page-experience signal exists. Mobile rendering, security, intrusive ads/interstitials, and content visibility matter to overall experience. | [Understanding page experience](https://developers.google.com/search/docs/appearance/page-experience); [Core Web Vitals](https://developers.google.com/search/docs/appearance/core-web-vitals) |
| Spam policies | Keyword stuffing, hidden text/link abuse, link spam, doorway abuse, scraping, and scaled content abuse can lead to lower ranking or omission. A score should not reward practices that encourage repetition, thin mass-produced content, or manipulative links. | [Spam policies for Google Web Search](https://developers.google.com/search/docs/essentials/spam-policies) |

## Implications for interpreting a score

- Treat checks like title/description completeness, basic crawl directives, alt coverage, or schema parseability as checks of controllable page hygiene, not direct measurements of rankability.
- A character target, word-count target, keyphrase count/density, heading count, or fixed number of links can be an optional editorial prompt. It should not be described as a Google requirement or ranking threshold unless Google explicitly documents one.
- Distinguish observable machine checks from qualitative judgments. Source-code presence can be assessed deterministically; originality, expertise, usefulness, intent satisfaction, alt-text relevance, and factual accuracy need human/content-context review.
- Separate technical eligibility from outcome: a page may pass checks and still not be indexed, shown with its intended title/snippet/rich result, or rank well.
- Scores should expose criteria, applicability, weighting, evidence, and uncertainty. A 0–100 scale is useful for prioritization only if it does not imply comparability across unlike page types or a Google-issued verdict.

The links above are live Google Search Central documentation checked on 25 October 2026. Google's systems and documentation evolve; revisit the linked guidance when changing rules or weights. This memo summarizes guidance and does not represent private knowledge of Google's ranking algorithms.
